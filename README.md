# 클로드 모니터링

이 PC에서 실행 중인 **Claude Code 세션**을 트레이 위젯으로 한눈에 보는 Windows 앱이에요.
어느 세션이 내 응답을 기다리는지, 무엇을 하고 있는지, 어느 브랜치에서 작업 중인지 바로 확인하고 필요하면 세션을 종료할 수 있어요.

> **토큰을 쓰지 않아요.** 위젯은 로컬 파일만 읽는 독립 프로그램이라 LLM·네트워크 호출이 전혀 없어요.

## 주요 기능

- **트레이 아이콘**: Claude 캐릭터 + 오른쪽 아래 상태 점 (회색: 쉬는 중 / 초록: 작업 중 / 빨강+숫자: 응답 필요)
- **건수 요약**: 최상단 타일에 세션 / 작업 중 / 입력 대기 / 쉬는 중 / 서브에이전트 건수 표시
- **세션 카드**: 상태 → 제목 → 작업 폴더·브랜치·변경 파일 수·원격 대비 앞섬/뒤처짐
- **제목 없는 세션 구분**: 지어낸 제목 대신 실제 입력한 "최근 요청 / 첫 요청" 문장을 그대로 표시
- **서브에이전트 목록**: 실행 중인 서브에이전트(code-reviewer 등)를 별도 구역에 표시
- **즉시 종료 버튼**: 카드의 `종료`를 누르면 해당 세션 프로세스를 바로 종료
- **핀 고정**: 우측 상단 핀으로 화면에 고정(바깥을 눌러도 닫히지 않음), 드래그·크기 조절, 위치·크기 기억
- **사용량 표시(예정)**: statusLine 연동으로 컨텍스트·5시간/주간 사용량 수집 준비

## 요구 사항

- Windows 10/11
- Node.js 20 이상
- Claude Code (CLI 또는 데스크톱)

## 설치와 실행

```powershell
git clone https://github.com/jiny-01/claude_monitoring.git
cd claude_monitoring
npm install
npm start
```

- 실행하면 작업 표시줄 오른쪽 아래(숨겨진 아이콘 `^` 안쪽)에 아이콘이 생겨요. 클릭하면 패널이 열려요.
- 우클릭 메뉴에서 **로그인 시 자동 실행**을 켤 수 있어요.
- `gen-icon.js`로 `icon.ico`를 다시 만들 수 있어요: `node gen-icon.js`

## 작업 표시줄에 고정하기

1. `electron.exe`를 가리키는 바로가기를 만들어요.
   - 대상: `<설치 경로>\node_modules\electron\dist\electron.exe "<설치 경로>"`
   - 아이콘: `<설치 경로>\icon.ico`
2. 바로가기를 우클릭 → **작업 표시줄에 고정**

## 사용량 수집 설정 (선택)

`~/.claude/settings.json`에 아래를 추가하면 statusLine 입력을 파일로 저장해요(화면 출력 0바이트, 토큰 0).

```json
"statusLine": {
  "type": "command",
  "command": "node <설치 경로>\\statusline.js"
}
```

- 저장 위치: `%LOCALAPPDATA%\claude-board\status\<session_id>.json`
- 제거하려면 위 블록만 지우면 돼요.

## 세션 제목 규칙

제목을 지어내지 않고 실제 값만 보여요. 우선순위는 다음과 같아요.

1. 위젯에서 이름을 더블클릭해 직접 지정한 제목
2. Claude 데스크톱 앱의 세션 제목
3. 세션에서 `/rename`으로 지정한 제목
4. 위 값이 없으면 원래 별칭(예: `geodap-40`)을 회색으로 표시하고, 아래에 실제 요청 문장을 함께 보여 줘요

## 읽는 데이터와 보안

| 항목 | 위치 | 용도 |
|---|---|---|
| 세션 상태 | `~/.claude/sessions/<PID>.json` | 목록·상태·PID |
| 제목 | `~/.claude/projects/*/<sessionId>.jsonl`, Claude 앱 세션 저장소 | 제목 조회 |
| 서브에이전트 | `~/.claude/projects/*/<sessionId>/subagents/` | 실행 중 여부 |
| git 상태 | 작업 폴더의 `git status` (읽기 전용) | 브랜치·변경 수 |

- 인증 정보(`.key`, 토큰 파일)는 읽지 않아요.
- 종료 버튼은 세션 파일의 프로세스 시작 시각과 실제 프로세스를 대조한 뒤에만 종료해요(PID 재사용 방지).
- 종료는 되돌릴 수 없고, 저장하지 않은 작업이 사라질 수 있어요.

## 배포용 빌드

```powershell
npm run dist
```

- `dist/`에 Windows 설치 파일과 포터블 실행 파일이 만들어져요(`electron-builder`).
- Windows에서 심볼릭 링크 권한이 필요해요. **설정 → 개발자용 → 개발자 모드**를 켜거나 관리자 터미널에서 실행하세요.
  (권한이 없으면 `Cannot create symbolic link` 오류가 나요.)
- 압축 해제 형태만 빠르게 확인하려면 `npx electron-builder --win dir`
